USOS Y BENEFICIOS (Información referencial)
=================================
- Para la fiebre: Paracetamol 500mg es el más recomendado. También Ibuprofeno 400mg ayuda a bajar la fiebre.
- Para el dolor de cabeza: Aspirina 500mg o Paracetamol 500mg son efectivos.
- Para el dolor muscular o inflamación: Ibuprofeno 400mg es antiinflamatorio.
- Para la gripe o resfrío: Vitamina C 1000mg fortalece las defensas, Paracetamol para la fiebre.
- Para la acidez o gastritis: Omeprazol 20mg, tomar media hora antes de las comidas.
- Para la tos: Jarabe para la tos, tomar 10ml cada 8 horas.
